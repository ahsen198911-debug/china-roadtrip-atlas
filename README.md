# 全国自驾线路图鉴

静态站点，GitHub Pages 托管，零服务器成本。

## 本地重建
```bash
python3 ~/.hermes/scripts/site_build.py
```

## 目录
- `index.html` 首页（线路总表）
- `routes/<线路>.html` 逐日路书单页
- `assets/style.css` 样式
- `sitemap.xml` / `robots.txt` SEO

## 询盘
每个页面「定制咨询」按钮 → 预填 GitHub Issue（label: `inquiry`）。
访客无需注册，点一下即提交。
